# Better URL Bench

A basic benchmarker for [Better URL](../better-url) by comparing it with Servo's URL crate and Ada's URL crate.

## TL;DR

If all you're doing is parsing short URLs, Ada is faster for you.

If you expect to parse significant amounts of long URLs, Better URL may be faster for you.

If you expect to do even slight modifications to URLs of any length, Better URL will be significantly faster for you.
